# Learn Gavin's click habits separately for each display layout

References: ForesightJS's [geometry-aware mouse predictor](https://github.com/spaansba/ForesightJS/blob/f2aedc975ea3e4d755c908d612deda59bddf8b79/packages/js.foresight/src/predictors/MousePredictor.ts), ClickSense's [spatial approach collector](https://github.com/andyed/clicksense/blob/2daacb746cde45614725e3e65e945354b66f5b3d/src/clicksense.js) and OpenAdapt's [geometry-associated recorder](https://github.com/OpenAdaptAI/openadapt-capture/blob/6e2e1ad6e882a99b6e6e742a85cb812aee82c59f/openadapt_capture/recorder.py). Our independent inference is that identical absolute coordinates must not be treated as the same personal click context across changed displays. No external model or cognitive-confidence interpretation is imported.

Existing display records already contain global origins, logical dimensions and pixel dimensions. Analysis fingerprints sorted geometry, excluding transient display IDs and clicked positions. New schema-2 count models and their app-popularity baseline key on app + display geometry (+ previous cell for transitions). An unseen layout abstains instead of borrowing another layout's clicks. Chronological evaluation uses only geometry observed by each event; it never uses the target's final position to construct a layout key.

The menu, raw coordinates, personal settings and analysis command are unchanged. Heatmaps include per-layout counts/geometry alongside backward-compatible descriptive totals. Unknown/corrupt geometry is isolated by session/segment; loss invalidates geometry until an explicit complete batch restart. The recorder emits each display batch synchronously, before another input callback can run. Valid display order and changed transient IDs do not alter the geometry fingerprint.

Legacy schema-1 models remain readable without a layout argument, but cannot claim a match to an explicitly supplied layout. Retrain them from your own captures to gain layout-aware counts. Window movement and semantic target identity within a fixed monitor layout are still unmodeled; no accuracy or full-target-recognition claim is made.
